## Interview Questions and Answers

**1. What is data processing?**  
Data processing involves collecting, cleaning, organizing, and transforming data into useful information.

**2. Why are functions useful in data processing?**  
Functions improve code reusability, readability, and maintainability.

**3. What is structured data?**  
Structured data is organized in a predefined format, such as rows and columns or dictionaries with fixed keys.

**4. What is a dictionary in Python?**  
A dictionary stores information as key-value pairs.

**5. What are summary statistics?**  
They describe a dataset using measures such as mean, minimum, maximum, and count.

**6. What is data cleaning?**  
Data cleaning identifies and handles missing, invalid, duplicate, or inconsistent records.

**7. What is a lambda function?**  
A lambda function is a small anonymous function that can be used for operations such as sorting records by marks.

**8. What is the difference between `sum()` and `len()`?**  
`sum()` calculates the total of numeric values, while `len()` returns the number of items.
